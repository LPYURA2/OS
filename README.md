# StyleOS

StyleOS — самостоятельная операционная система для x86‑64 и AArch64. Мы строим одно рабочее пространство для ПК и телефона с внешним монитором. На собственном экране телефона предполагается мобильный интерфейс, на мониторе — общий десктоп StyleOS с небольшими отличиями под устройство.

Идея проекта — дать пользователю контроль над файлами, задачами и обновлениями и упростить работу между приложениями. Первый пример — сохранить документ и передать только этот выбранный файл другому приложению через Deep Drop. StyleOS использует собственное ядро на C и платформенный ASM. Стандартные инструменты и подходящие библиотеки можно использовать повторно.

## Что доступно сейчас

**Инженерный прототип, не готовая ОС для повседневной работы.** Старт x86‑64 UEFI и AArch64 QEMU, дисковые эксперименты, запуск отдельной программы AArch64 и графический диагностический экран уже проверялись. Диагностический экран не является рабочим столом. Он не включает ввод, редактор, файловый менеджер или установку приложений.

- [Актуальный проверенный код](https://github.com/LPYURA2/OS/tree/c162995c4390686bda54468f68f40164b3c4f3bc) — графический x86‑64 тест и оба исправления Termux для T‑P1.8B.
- [Как собрать и проверить диагностические образы](docs/QUICKSTART.md). Linux/QEMU и контроль владельцем в Termux подтверждены. VirtualBox и нативное железо проверяются отдельно.
- [Releases](https://github.com/LPYURA2/OS/releases). На дату среза 17 ноября 2026 года публичных релизов нет. Диагностические образы не объявлены выпуском.

## StyleOS Desktop v0

В ветке `feature/styleos-desktop-v0` отдельный интерактивный образ x86‑64 UEFI. Мышь, окна, «Файлы», редактор и сохранение на втором виртуальном диске проверены в QEMU. Deep Drop в этот образ не включён. [Установка, функции и проверки Desktop v0](docs/test-results/desktop-v0/README.md)

После первого запуска на ноутбуке в VirtualBox проверили видео с мерцанием
старой сборки при движении мыши. Обновлённый рендерер обрабатывает только
изменённые области. Повторная проверка в VirtualBox ещё предстоит.
[Исправление и тесты отрисовки](docs/test-results/desktop-cursor/README.md)

В Desktop v0.2 «Файлы» обозначены иконкой окна с боковой панелью.
«Проекты» и каталоги внутри окна сохранили значок папки.
[Обновление системного диска и результаты проверок](docs/test-results/desktop-files-icon/README.md)

Desktop v0.3 в ветке `feature/styleos-desktop-v0-3-iso` загружается с ISO
без установки. Диск заметок остаётся отдельным и совместим с v0.2.
Панель «Процессы» пока показывает открытые окна.
[Запуск ISO и проверки](docs/test-results/desktop-iso/README.md)
