# MATRYOSHKA: карта исходного кода

**Экспонат для просмотра исходников, не новая версия ядра.** Основа: MATRYOSHKA Termux v0.3.2, проверенная на Android пользователем (12.11.2026). Код виртуального CPU, ядра и приложений в данной упаковке сохранён без изменений.

## Куда смотреть

| Компонент | Файл | Где выполняется |
|---|---|---|
| CPU M32, регистры, 33 операции | `matryoshka.py` — `VirtualMachine.step()` | Python-хост эмулирует железо |
| RAM, защита памяти | `matryoshka.py` — `reset()`, `_guard()` | Python-хост |
| Диск, видеопамять, клавиатура | `matryoshka.py` — `BlockDisk`, `_port()`, `_emit()` | Python-хост |
| Двухпроходный ассемблер M32 | `matryoshka.py` — `assemble()` | Сборка на Python-хосте |
| ROM/firmware | `firmware.asm` | Машинный код гостевого M32 |
| Ядро, планировщик, syscalls | `kernel.asm` | Машинный код гостевого M32 |
| Командная оболочка | `programs/shell.asm` | Машинный код гостевого M32 |
| Остальные приложения | `programs/*.asm` | Машинный код гостевого M32 |
| Образ диска с приложениями | `images/system.img` | Читает гостевая прошивка и ядро |
| M8 — второй CPU | `hardware_m8/m8.py` | Отдельная Python-модель, несовместимая с M32 |
| Логическая ALU M8 | `hardware_m8/gate_alu.py` | Python-модель цифровой логики |
| C движок и ABI | `engine_lab/src/mw_engine.c`, `engine_lab/include/mw_engine.h` | Нативная библиотека для хоста |
| C++ сцена | `engine_lab/src/mw_scene.cpp` | Нативный хост |
| Python-интеграция | `engine_lab/python/demo.py` | Хост |
| Java-интеграция | `engine_lab/java/MatryoshkaEngine.java` | JNI на хосте |
| C#-интеграция | `engine_lab/csharp/MatryoshkaDemo.cs` | P/Invoke, сборка не проверена |

**Не путать:** многопроцессная гостевая ОС пока минимальная, файловой системы с каталогами и GUI нет. Движок C/C++/C#/Python/Java — самостоятельная лаборатория, в гостевой ОС пока не работает. M8 пока не исполняет M32-программы. Исходник `matryoshka.py` также содержит ассемблер сборки, который работает до запуска гостевого CPU.

## Как показать другому человеку

1. Открой `CODE_TOUR.html` в Chrome/Firefox на ПК. Это полностью автономная офлайн-страница с настоящими текстами исходников.
2. В Termux можно выполнить `cd ~/matryoshka_showcase; python -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/CODE_TOUR.html` в браузере телефона. Выход из сервера: `Ctrl+C`.
3. В любом редакторе — открыть папку проекта, лучше VS Code. Это проще для полноценного редактирования.
4. В Termux текстовый просмотр: `less -N matryoshka.py`, `less -N kernel.asm`, `less -N engine_lab/src/mw_engine.c`.

## Проверки

```sh
python matryoshka.py --selftest
python -m unittest discover -s tests -v
python hardware_m8/m8.py --selftest
# engine_lab/build.sh: нужны clang/gcc, C++17 и Python; Java необязательна
```

Проверка целостности HTML после изменений: `python tools/generate_code_tour.py`; этот генератор берёт тексты непосредственно с диска и вставляет их в HTML для офлайн просмотра.
