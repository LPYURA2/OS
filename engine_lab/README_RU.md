# MATRYOSHKA ENGINE: первый прототип C + C++ + Python + Java + C#

Это **движок хоста**, не гостевой код для M8/MX32 и не полноценный оконный графический интерфейс. Программный framebuffer, сцена, PPM-снимки, C ABI. Без SDL и внешних графических библиотек.

## Linux / Termux (при наличии C/C++ компиляторов)

```bash
pkg install clang python openjdk-21 -y   # только в Termux, JDK если доступен; Java необязательна
cd engine
bash build.sh
```

В обычном Linux: `gcc`, `g++`, `python3`, опционально `javac` и `java`, и `./build.sh`. В Termux может понадобиться заменить явный `gcc` на `clang` и `g++` на `clang++`, а ветку JNI скорректировать под установленную JDK. Termux-сборка **не проверялась**, платформа может требовать адаптации.

Сборка C/C++ создаёт `build/libmatryoshka_engine.so`. Запуск C++ клиента, Python и Java производит равные PPM-изображения (`build/frame_*.ppm`); тест сравнивает байты.

## Windows

Можно использовать CMake (C/C++ компилятор должен быть установлен). См. `CMakeLists.txt`.

Для C# образец находится в `csharp/MatryoshkaDemo.csproj`. Требуется .NET 8 SDK и нативная библиотека по пути загрузчика. C# код не проверен локально, так как .NET SDK отсутствует.

## API

Все функции в `include/mw_engine.h`. Необработанные указатели `MW_Engine*` не должны переживать `mw_destroy`, нельзя одновременно менять framebuffer из разных потоков без синхронизации. Результаты `mw_save_ppm` нужно проверять. Проект демонстрационный, без sandbox для плагинов.
