MATRYOSHKA OS — ПОЛНЫЙ КОМПЛЕКТ (ПОВТОРНАЯ ВЫДАЧА)
Дата: 12.11.2026

Содержимое:
- рабочая сборка MATRYOSHKA Termux v0.3.2;
- материнский паспорт проекта v0.8.1 (MATRYOSHKA_RAZRYV_OS_MASTER.docx);
- код процессора M32, память, диски, firmware.asm, kernel.asm, приложения;
- hardware_m8: экспериментальный M8 для Proteus;
- engine_lab: независимый прототип C, C++, C#, Python, Java;
- CODE_TOUR.html — офлайн-просмотр исходников;
- AGENTS.md, docs и задания для Codex.

Как загрузить в GitHub OS:
1) Распаковать ZIP.
2) Загрузить СОДЕРЖИМОЕ ZIP в корень репозитория OS.
3) Не загружать ZIP единым файлом вместо исходников.

Быстрая проверка в Termux после распаковки:
  python matryoshka.py --selftest
  python tools/export_images.py --check
  python matryoshka.py --os

Важно: это текущая рабочая ОС v0.3.2, а не новая функциональная версия.
