# MATRYOSHKA OS Changelog

## Termux v0.3 (12 ноября 2026) — экспериментальная ветка
- Guest shell: `save <text>`, `load`, `ls`, `rm` для одной записки NOTE.TXT в секторе 80.
- Путь к пользовательскому диску отделён от прежнего v0.2 (`matryoshka_user_disk.img`).
- Ввод и эхо UTF-8 (в том числе русский) через гостевую клавиатуру.
- Файл дискa на хосте записывается атомарно через временный файл и os.replace.
- Добавлен интеграционный тест сохранения/чтения/удаления при reboot с временным образом диска.
- `tools/export_images.py`: бинарные firmware/kernel/shell и SHA-256 manifest.
- Новая дорожная карта Termux и проект ADR для унификации ISA.

## v0.2 — базовая линия
- Guest shell: help, ps, info, clear, exit; моделирование клавиатуры/экрана.
- M8 как отдельная аппаратная линия, ROM BIN/HEX, golden trace и логическая ALU.

## Termux v0.3.1 (12 ноября 2026) — ROM Boot Experiment
- Двоичный `firmware.bin` устанавливается хостом в ROM; kernel.bin не предзагружается хостом в RAM.
- Гостевой firmware.asm читает заголовок и ядро из `images/system.img` через устройство с портами OUT 50/51/52 + IN 53.
- Заголовок `MTRX`, длина, N секторов, checksum суммы 32-битных слов; при повреждении образа — BOOT ERROR и HALT.
- Разделены системный диск только для чтения и пользовательский диск с NOTE.TXT.
- `tools/export_images.py` строит воспроизводимые `firmware.bin`, `kernel.bin`, `shell.bin`, `system.img` и SHA-256 manifest.
- Тестируется пустая RAM ядра перед включением CPU, ROM-boot, работа shell и сохранение NOTE.TXT после reboot.
- Предупреждение: guest apps preloaded хостом; ISA M32 экспериментальная; Proteus не начат.

## Termux v0.3.2 / T1A (12 ноября 2026) — guest app loader
- Гостевой kernel.asm читает каталог `MAPP` (сектор 17) и исполняемые бинарники из `SYSTEM.IMG` с помощью CPU-инструкций. Python больше не загружает программы из `.asm` при запуске VM.
- Каталог MAPP строится `tools/export_images.py` вместе с детерминированными бинарниками всех 6 программ `images/apps/*.bin`; SHA-256 записывается в manifest.
- Добавлен экспериментальный syscall `TRAP 10`, команда гостевой shell `run 0..4`, проверка живого процесса перед перезаписью его памяти и отказ при полном списке PID.
- Добавлены 5 отдельных тестов T1A (в том числе долгоживущий процесс и попытка повторного запуска), расширен самотест, сохранены старые тесты.
- Системные и пользовательские диски раздельны. Никаких изменений M8 и без переноса на RISC-V/Proteus.
- На устройстве владельца v0.3.2 ещё не проверялась; это эксперимент, а не стабильный релиз.
