# Подтверждённая поставка обзора исходников (без изменения ядра)

Дата: 12 ноября 2026.

Функции: автономный HTML-обозреватель, карта компонентов, CLI-инспектор исходников, добавлен раздельный `engine_lab` с C/C++/C#/Python/Java. В основе — v0.3.2. Это не v0.3.3 и не закрытие T1B.

Гарантии: содержимое исходников ОС/ASM и бинарных образов совпадает с исходным архивом MATRYOSHKA_Termux_v0.3.2.zip. Скрипт `tools/generate_code_tour.py` воспроизводимо встраивает тексты локальных файлов в HTML, не пользуется интернетом.

Проверки в Linux: `python matryoshka.py --selftest`: PASS; `python -m unittest discover -s tests -v`: 5/5; `python hardware_m8/m8.py --selftest`: PASS; `cd engine_lab && bash build.sh`: C++, Python, Java — одинаковый кадр (контрольная сумма dc0b9529). C# локально не проверялся: нет .NET SDK.

Новые инструменты имеют доступ только на чтение исходников и НЕ изменяют поведение гостевого CPU и ядра. Дальнейший T1B: исправить CONSOLE-001, выработать единый TTY/очередь событий и регрессионные тесты.
