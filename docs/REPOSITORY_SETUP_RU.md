# Подключение репозитория `OS` к Codex и ChatGPT

Актуализация: 12.11.2026. Репозиторий создан пользователем, но **его наличие в выбранной среде Codex пока не подтверждено**. Подключение GitHub к ChatGPT и назначение репозиториев среде Codex — разные операции.

## Прямые адреса

- Приложение Codex: https://github.com/apps/chatgpt-codex-connector
- Управление установленными GitHub Apps: https://github.com/settings/installations
- Codex: https://chatgpt.com/codex
- Настройки Codex Cloud: https://chatgpt.com/settings/codex-cloud
- Инструкция: https://learn.chatgpt.com/docs/environments/cloud-environments
- Отдельно для ChatGPT: Settings → Plugins → GitHub → repository management.

## Порядок действий на Android / в браузере

1. В GitHub под учётной записью владельца `OS` открой приложение ChatGPT Codex Connector; установи/Configure и выдай доступ **только** к репозиторию `OS` (Only select repositories). Принадлежность аккаунта важна.
2. В Codex создай/выбери облачную среду, подключи `OS`, проверь чтение `README.md` и `AGENTS.md` (если среда новая, сначала Create environment → Publish).
3. Первую задачу попроси **без изменений кода**: показать дерево проекта, назвать текущую версию v0.3.2, запустить тесты и дать список ограничений. Никаких изменений main, никакого самостоятельного merge.
4. После этого запускай узкие задачи через feature-ветку и Pull Request с тестами, рисками и инструкциями проверки на Android.
5. Если `OS` не виден, перепроверь выбранный аккаунт/организацию и настройки конкретного GitHub App, затем что среда Codex действительно использует этот репозиторий.

## Чистота репозитория

Извлекай **содержимое** текущего пакета в корень `OS`, а не загружай один ZIP. Не включай `matryoshka_user_disk.img`, ключи, токены, записи личного терминала, случайные временные файлы. Рабочая v0.3.2 должна быть зафиксирована отдельным коммитом и тегом; документальные обновления отделяй от кода.

## Если репозиторий уже содержит файлы

Не делай `git push --force` и не замещай его вслепую. Сначала сравни текущее дерево `OS` с данным пакетом. Проверь, что в main уже нет более свежих принятых изменений и что базовый коммит воспроизводим.

## Обновление: репозиторий OS найден, но он пуст и публичен (12.11.2026)

GitHub-подключение показывает `LPYURA2/OS`, видимость `public`, размер `0`. При этом в мобильном Codex доступны лишь «Мессенджер» и «По умолчанию»: создание и публикация среды выполняются в браузере или приложении для ПК, а затем опубликованная среда будет доступна на Android.

Открой [Codex](https://chatgpt.com/codex) в браузере (при необходимости включи режим ПК), затем `Work in → Cloud → Select environment → Create environment`, выбери `OS`, выполни `Get started`, после проверки `Publish`. Альтернатива: `Settings → Codex Cloud → Environments`. Не изменяй среду мессенджера. Референс: https://learn.chatgpt.com/docs/environments/cloud-environments .

Если `OS` отсутствует в выборе репозиториев, проверь установку Codex GitHub App именно у владельца `LPYURA2` и разрешение на `OS`: https://github.com/settings/installations . До загрузки пакета реши, должен ли репозиторий оставаться публичным. Сначала загрузи файлы в корень репозитория, а не один ZIP.
