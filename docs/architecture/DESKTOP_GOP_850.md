# S850: first desktop mapping composition input (draft)

The terminal S842-S849 chain has no ordinary Desktop framebuffer mapping. This module consumes the existing S795 BAR decoder, S800 MTRR evaluator, S801 inherited walk, GOP surface validation, and the S842 cache snapshot. It proposes one page-covered identity RW/NX supervisor framebuffer range (separate UC PAT bits). It caps the mapped span at 16 MiB, maps only full pages needed for stride * height * 4, requires padding contained in the reported GOP buffer, checks BAR raw base/type/size, rejects RAM/candidate and live image/stack/handoff/map/workspace overlap. Final UEFI descriptors must be structurally non-overlapping; any intersecting descriptor must be non-runtime MMIO. An absent descriptor is not proof of ownership. Each page's start and end must be identity translated with inherited WB or UC PAT and physical UC MTRR. Variable MTRR masks must be contiguous/aligned. Refusal clears the proposal. No writes to hardware or to inherited page tables.

Caller must establish **same-boot** provenance: actual GOP capture, unique display BAR with measured aperture and restoration or trusted firmware resource bounds, actual final UEFI map, physical table-read authority, stable cache/mode, and compatible aliases. This module cannot authenticate supplied inputs or prove exclusive PCI ownership or absence of global aliases. Prior runs must not be recycled as current evidence. The page-walk callback is trusted; `ready` means proposal only, not permission. The draft's tests use synthetic descriptors and table reader, not live QEMU. The 16 MiB bound and UC are conservative initial x86-64 QEMU profile choices, not universal hardware requirements or permanent cache policy.

## Detached composition extension

A new, nonoverlapping 32-page table buffer must be fully contained in an existing admitted RW/NX normal-memory extent. It preserves every source mapping, appends only the validated GOP mapping, uses the common `pg_build` constructor and patches the exact detached device leaves to the admitted UC PAT index. It never accesses the temporary WB MMIO mappings. `s850_desktop_audit` revalidates both inputs, walks the complete bounded tree, rejects unexpected leaves, duplicate/reused/foreign table pointers, missing mappings, incorrect permissions/cache bits and nonzero unused tables. Accessed/dirty changes are allowed only for existing entries. A failed output is not a root grant. Obvious output and table aliases are refused before modification; caller must attest all nested metadata spans and address correspondence, and keep the old and new tables detached during construction. No actual GOP write or CR3 switch.

This detached low root does not yet incorporate the separate high guarded IST aliases that were materialized by the S785/S846 activation path. The same-boot integration must explicitly reconstruct/verify them and all live references before any switch. Do not take `ready` as authority to activate. No claim about firmware aliases, DMA enforcement or supported GPU cache policies beyond the synthetic fixture.
