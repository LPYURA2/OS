# StyleOS Processes.tea — диспетчер задач

Смысл приложения: аналог Windows Task Manager, с переиспользованием удачных принципов, но в собственной оболочке и с утверждённой палитрой StyleOS.

Первый выпуск: вкладки Процессы, Производительность и Подробности. Службы — после появления реального сервисного менеджера. Группы: Приложения, Фоновые процессы, Системные процессы. Реальные PID, PPID, статусы, память и время CPU — только из ядра.

Для обычных приложений завершение задачи требует отдельного защищённого IPC-вызова, проверки полномочий и подтверждения. Ядро и критические службы завершить через UI нельзя. Закрытие окна не равно завершению процесса; F10 не меняет PID и память приложений.

Добавлено сейчас: чистая функция pi_view() в kernel/process_view.c. Поиск по имени (ASCII без регистра) и подстроке PID; сортировка внутри групп по PID, имени, CPU ticks, RAM и состоянию; истинные счётчики и корректное усечение; тесты ASAN/UBSAN и x86-64 COFF.

Ограничение: это модель просмотра реальных записей, а не готовый Processes.tea. Системный планировщик пока не заполняет эти записи полноценными событиями; процент CPU, графики производительности и действительно работающие процессы в интерфейсе не заявлены. Нужны CPL3, API процессного снимка, безопасность IPC, настоящий исполняемый пакет .tea. Старый F8 перечисляет только временные сеансы, не настоящие процессы.

Рабочий стол, цвета, desktop_shell.c и desktop_draw.c не изменять. Новые системные окна строить по утверждённым макетам, а не копировать Windows визуально.
