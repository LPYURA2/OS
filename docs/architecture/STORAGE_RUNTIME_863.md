# S863 bounded storage runtime component
This is a host contract and freestanding module candidate for a disposable 4096-sector fixture, not an ordinary disk driver. It does not touch physical I/O and is not linked into existing EFI profiles. It admits one bounded sector range only when same-boot root, epoch, device identity, exclusive PIO, kernel context, single CPU, post-EBS, DMA denial and disposable media are explicitly supplied; write authority additionally requires flush. Each backend operation is surrounded by observation checks, no reentry, no out-of-range I/O, sticky quarantine on loss or error. Single sector commit copies input, writes, flushes and reads back; a failed write or flush may change media and quarantine is not rollback or atomic power-loss durability. Read failure does not publish partial data. Host checks stale authority at every observation, out-of-range access, read-only writes, backend failures and corrupted readback, reentry, and no calls after quarantine. GCC/Clang ASan+UBSan and freestanding COFF compile added to existing bootstrap CI; previous mandatory tests retained. Actual PIO backend must independently attest device and geometry, legacy port decode, bus-master disable and idle DMA, runner-owned disposable data disk, and exclusive port ownership before any read/write, then prove separate-boot readback with raw evidence. Do not turn the old terminal grant into general access. Main and accepted branches untouched. No new hardware capability claimed; 863 remains open. Prior RTC guest CI 45674426850 was still running during this work.
