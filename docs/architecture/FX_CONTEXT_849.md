# S849 — bounded legacy FP/SIMD context (local draft)

Candidate base S848 `5015936db5ab5d47c0230434dfb1c512a5891c73`, run `45461288933` (not accepted when drafted). No GitHub changes or ordinary Desktop changes. This is a proposed isolated extension for KFA-06, not a production CPU ABI choice.

The model admits only x87/FXSR/SSE/SSE2, CR0.MP/NE=1, EM/TS=0, CR4.OSFXSR/OSXMMEXCPT=1, OSXSAVE=0 in both CR4 and CPUID. It never writes control registers. Two distinct root-bound 512-byte aligned snapshots; initial FCW 0x037f, MXCSR 0x1f80, all register bytes zero. The effective MXCSR mask uses the observed low 16 bits, with architectural 0xffbf fallback if the reported mask is zero. High extensions are deliberately not exposed. Invalid MXCSR, wrong root/token, double dispatch, active retirement and overlapping input/output are refused. Retirement scrubs the entire slot. No reallocation of retired slots or SMP; initial generation is 1, and this is not a general cross-bank generation guarantee. The trusted caller supplies actual hardware evidence and kernel-owned storage; this module does not authenticate pointers or prove address mappings. Fresh bank must be zero-initialized.

The SysV host-only assembly performs actual FXSAVE64/FXRSTOR64 roundtrips A -> B -> A and restores original legacy caller state. The test verifies all sixteen 128-bit XMM registers, FCW, x87 tag and one 80-bit x87 value, and distinct MXCSR. Host hardware may have OSXSAVE enabled; host test does not call privileged admission or assert guest eligibility. Actual reported host MXCSR mask was 0x0002ffff; model intentionally restricts the legacy subset. The test is not guest CPL3, timer or kernel FP evidence. GCC/UBSan model 937 assertions, real host roundtrip 783 additional assertions each (byte comparisons, not distinct scenarios), freestanding model COFF compilation. No guest run.

Next, after S848 acceptance: create a separate S849 branch/profile. Prove live CPUID and CR0/CR4 conditions before any FX operation; do not silently clear OSXSAVE or TS to force admission. If unavailable, report refusal and design a separately reviewed mode transition. Audit actual aligned kernel and process buffers in SAFE and both children. Save original kernel legacy state; restore only validated trusted process state before IRETQ. In assembly trap path save user state before any C call and restore kernel state before invoking dispatcher; retain IF=0, verify actual frame/root/current ownership, handle syscall-return and terminal paths. No kernel SIMD generated by compiler. Use distinct relocation-free user SSE2/x87 fixtures and verify actual register snapshots at IRQs plus post-fault survivor; scrub retired snapshots on SAFE. Preserve S848 profile and all prior behavior. No AVX/XSAVE, SMP, #NM lazy switching or production authority. Full QEMU, strict UART and regression needed; foundation remains incomplete.
