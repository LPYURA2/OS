## Large-file direction
Reuse proven StyleFS copy-on-write metadata/payload discipline rather than an incompatible silent v2 change. Next implement a separately identified wide metadata format and allocator using 64-bit sizes/LBAs and multiple extents; validate all on-disk arithmetic and disjoint extents, bounded metadata and durable publication, including interruption/recovery and migration on explicit new destination. Then connect extent window layer to real file create/read/write/copy/download jobs with cancellation and progress. Integrate validated LBA48 or other large-device backend; no arbitrary file-size cap except representable format, available capacity and explicit resource limits. Use actual >4 GiB file creation/copy/reopen tests with bounded memory and verified source/target. Deep Drop must use the same handles and streaming, never raw user sectors. Keep approved hierarchy, rights and ordinary boot.
