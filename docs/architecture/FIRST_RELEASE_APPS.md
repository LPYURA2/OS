# StyleOS — обязательный комплект первой полноценной версии

Решение владельца: 21 ноября 2026. Девять приложений должны поставляться вместе с ОС, но работать как самостоятельные native .tea, а не встраиваться в desktop_shell.c.

| ID пакета | Русское название | Обязательный статус |
|---|---|---|
| org.styleos.explorer.tea | Проводник | предустановленное |
| org.styleos.settings.tea | Параметры | предустановленное |
| org.styleos.notes.tea | Заметки | предустановленное |
| org.styleos.editor.tea | Текстовый редактор | предустановленное |
| org.styleos.documents.tea | Документы | предустановленное |
| org.styleos.spreadsheets.tea | Таблицы | предустановленное |
| org.styleos.presentations.tea | Презентации | предустановленное |
| org.styleos.browser.tea | Браузер | предустановленное |
| org.styleos.processes.tea | Процессы | предустановленное |

Единственный родной формат — .tea. Исторический .sapp не переносить. Будущая совместимость Android APK и Windows EXE — отдельные системные подсистемы.

Каталог installer/system-apps.json — обязательный состав и стабильные ID. До появления настоящих бинарников девяти приложений и рабочего установщика список является КОНТРАКТОМ, НЕ заявлением об успешной установке.

Нужно: отдельный CPL3 ELF loader, адресные пространства и безопасный syscall/IPC ABI; реестр установленных пакетов; брокер файлов, окон и разрешений; предустановка девяти работающих .tea; настоящие независимые PID и сохранение черновиков при F10. При отказе одного приложения остальные должны продолжать работу.

Продолжаем восстанавливать 730: в QEMU два настоящих StyleFS v2 диска, далее Проводник с реальной навигацией по обоим томам, фоновое копирование/отмена и графический установщик. Уже работающий рабочий стол и палитру не менять. Проводник — строго 20 утверждённых экранов, Документы — 14.
