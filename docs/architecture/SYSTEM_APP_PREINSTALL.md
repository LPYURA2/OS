# Подготовка предустановки native .tea

installer/system-apps.json — единый обязательный список девяти приложений. Host-инструмент tools/preinstall_tea.py: проверяет полное наличие и identity девяти реальных .tea пакетов, SHA256 и ELF CPU, затем **только** при успехе атомарно формирует временное дерево System/Applications с index.json.

Неполный, повреждённый, посторонний, неверно названный или .sapp набор отклоняется; прежний установленный каталог не перезаписывается. Использовать только для подготовки будущего установочного образа, не для записи в пользовательский VDI.

Пример: python3 tools/preinstall_tea.py check-catalog; python3 tools/preinstall_tea.py stage --packages /dir/with/nine/tea --output /new/empty/staging.

Сейчас настоящих девяти функциональных пакетов нет. CI собирает временные тестовые ELF заглушки исключительно в тестовой директории, проверяет инструменты и удаляет фикстуры. **Они НЕ являются системными приложениями и НЕ попадают в ISO**.

Реальный установщик и запуск независимых .tea пользовательских процессов будут введены отдельными этапами. Полная изоляция приложений пока НЕ готова.
