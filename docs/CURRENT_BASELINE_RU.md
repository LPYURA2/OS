# Подтверждённая база MATRYOSHKA (12.11.2026)

**Рабочая версия ОС: Termux v0.3.2 / T1A.** Последний результат владельца: Android/Termux SELFTEST PASS, загрузка ядра с SYSTEM.IMG, `run 0` hello, `run 1` counter, `ps` после завершения показал PID 0. На скриншоте выявлено смешивание вывода фонового процесса с вводом shell (CONSOLE-001). Это базовая проверка на реальном устройстве, не полный приёмочный набор.

**Host Python:** собственная M32 ISA (33 инструкции), виртуальная RAM/ROM/порты/диски, ассемблер и эмуляция устройств; гостевые firmware/kernel/shell — ASM и исполняются на M32. Гостевой загрузчик приложений читает MAPP-каталог из SYSTEM.IMG и загружает выбранные программы в слоты RAM. Диск пользователя отдельно, сохраняет одну NOTE.TXT, не является общей FS.

**Другая ветка:** аппаратный учебный M8 (25 инструкций) и golden trace для будущего Proteus; не совместим с M32. Proteus-схема физически ещё не запущена.

**Отдельная лаборатория:** `engine_lab/` — минимальный C/C++-рендерер, Python и Java вызовы работают в Linux-тестах; C# исходник существует, сборка не подтверждена. Не выполняется внутри гостевой ОС.

**Ещё нет:** окончательной ISA/ABI, ядра на C, полноценной файловой системы, GUI, процесса установки `.tea`, Android APK и Windows EXE compatibility, производственных уровней безопасности и оптимизаций, ARM64/x86-64 портов, запуска в Limbo/Proteus.

**Состояние пакета:** документация + исходный код из подтверждённой Source Showcase r1 на базе v0.3.2; функциональные исходники и образы не модифицировались. Проверка пакета в Linux: SELFTEST PASS, images CHECK PASS, unittest 5/5 PASS, M8 SELFTEST PASS, ALU 327680 PASS. Это не новый функциональный релиз ОС.
