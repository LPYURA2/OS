# «Документы» — этап 756: редактирование и проверки

База `feature/styleos-documents-runtime-755`, коммит
`3ec21ba2c765f327127e72516ef73200d09062f8`. Новая ветка
`feature/styleos-documents-edit-756`.

## Изменения

- `modules/documents/edit.c` — точный UTF-8 поиск и атомарная замена всех
  совпадений. При нехватке места текст/курсор/комментарии остаются неизменны.
  Совпадения внутри комментариев инвалидируют якорь, до них — смещают.
- `modules/documents/history.c` — 4 снимка отмены и 4 повтора с учётом
  комментариев, позиции курсора и свойств страницы. История сбрасывается
  при открытии и создании нового документа, ошибки не добавляют шагов.
- `modules/documents/runtime.c` — обработка поиска, перехода, замены одного
  выделенного совпадения/всех, Undo/Redo, с сохранением разделения между
  приложением и оболочкой. Не существует несанкционированного доступа к путям.
- `modules/documents/ui.c` — Ctrl+A/F/H/Z/Y, действующие элементы поиска и
  замены, визуальная подсветка выделения на странице. Приблизительные
  метрики шрифта — ограничение текущего canvas. Диалоги поиска/замены
  остаются задачей хозяина интерфейса, их вызов подтверждён только на хосте.
- `.tea` собирается детерминированно, манIFEST остаётся
  `installable_in_744=false` и без доверенной подписи.

## Подтверждено

- GCC и Clang: `tests/test_documents_edit.c`,
  `tests/test_documents_edit_runtime.c`, прежние host-тесты.
- ASan/UBSan для runtime, 1200 негативных DOCX из предшествующего набора.
- ELF x86-64 реально исполнялся под Linux с событиями поиска, замены,
  undo/redo, TXT/DOCX round-trip и draw; это **не гостевой StyleOS**.
- Повторная сборка `.tea` побайтно совпала с первой.
- Аудит ISO 744: SHA-256 совпал, ELF-оболочка не менялась.

## НЕ подтверждено и НЕ выполнено

- Полный DOCX Microsoft Word с DEFLATE и сложными стилями,
  таблицами/изображениями/сносками/колонтитулами.
- Подпись `.tea`, системная установка, loader ABI StyleOS 744.
- Гостевой QEMU, VirtualBox или железо; соответствие всех 14 макетов.
- Полноценное пользовательское окно поиска/замены в StyleOS.
- Файл заметок рядом с исходным DOCX: file broker не имеет права создавать
  соседний файл без отдельного разрешения пользователя.

**Контрольная 744 нетронута, исходники этапа сохранены отдельно.**
