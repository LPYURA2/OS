# StyleOS — актуальная точка продолжения (753 recovery)

**Контрольная рабочая ОС:** 744, без изменений. **Готового нового ISO нет.**

## Доступная исходная база
- `include/styleos/documents_model.h`, `modules/documents/model.c`: текст UTF-8, выделение, редактирование, комментарии, бумага/поля.
- `include/styleos/documents_review.h`, `modules/documents/review.c`: базовые проверки текста и запись правок; формат истории не DOCX.
- `include/styleos/documents_docx.h`, `modules/documents/docx.c`: экспорт ограниченного документа в открываемый DOCX (ZIP_STORED, plain text, основные размеры листа и поля). Не поддерживает богатые объекты; нет импорта DOCX.
- `tools/embedded_tea_catalog.py`: read-only инвентаризация встроенных `.tea`-манифестов 744 с проверкой целостности, не извлечение исполняемых пакетов.
- `tools/test_restore.sh`: автономная проверка в GCC, Clang и Python.

## Утверждённые ограничения
Все системные и сторонние нативные приложения являются `.tea`; только будущая совместимость APK/EXE исключение. Работающий стол 744 не заменять старым кодом. Интерфейс строго из `StyleOS-Documents-Full-Concept.pdf` (14 экранов). Deep Drop — отдельная функция обмена; `main`, Portable-os и диск данных не трогать.

## Что отсутствует для сдачи
Исходный системный GUI и app loader 744, исходники `Documents.tea` 744–749, реальное встраивание приложения в ОС, полная функциональность 14 экранов, пользовательский ISO/VDI со всеми функциями, гостевые тесты QEMU и приёмка VirtualBox. Одна внешняя приёмка только после полного завершения.

## Следующий технический шаг
Восстановить desktop runtime, loader `.tea`, файловые API, окно «Документов». Подключить восстановленный документный движок. Дальше вернуть полный редактор по макету, тесты сохранения DOCX и гостевую установку; лишь тогда выдавать полноценный ISO.
