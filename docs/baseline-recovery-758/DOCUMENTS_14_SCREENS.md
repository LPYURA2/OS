# Приложение «Документы» — карта экранов и приёмка

Источник: пользовательский `StyleOS-Documents-Full-Concept.pdf`, 15 страниц: обложка + 14 экранов (8 вкладок, стартовый экран и диалоги). Эта карта не заменяет визуальное соответствие макетам.

| Экран | Цель и обязательный функционал | Реально проверено в 757? |
|---|---|---|
| 01 Стартовый | новый документ, открыть, недавние | Частично: новый/открыть через брокер; нет полноценного стартового UI |
| 02 Файл | сохранение, «сохранить как», импорт, экспорт, печать, версии | Частично: TXT и ограниченный DOCX, сохранение через токен; печать/версии нет |
| 03 Текст | стили, шрифты, абзацы, списки, поиск/замена | Частично: поиск/замена/undo; форматирование не завершено |
| 04 Вставка | таблицы, изображения, фигуры, диаграммы, формулы, символы, колонтитулы | Нет |
| 05 Страница | формат, поля, ориентация, колонки, разрывы | Частично: параметры бумаги, не весь UI/разрывы |
| 06 Ссылки | оглавление, сноски, подписи, гиперссылки, библиография | Нет |
| 07 Проверка | орфография, комментарии, отслеживание, сравнение | Частично: модель комментариев/эвристики/истории, без полного UI |
| 08 Автоматизация | шаблоны, поля, фрагменты и слияние с данными | Нет |
| 09 Вид | структура, чтение, масштаб, линейка | Частично: линейка/базовый холст |
| 10 Свойства абзаца | отступы, интервалы, выравнивание | Нет полного UI |
| 11 Свойства изображения | размеры, обтекание, позиция, альтернативный текст | Нет |
| 12 Открыть документ | выбор папки и существующего файла | Частично: запрос диалога через брокер |
| 13 Сохранить как | место и имя нового файла | Частично: запрос диалога через брокер |
| 14 Предпросмотр печати | лист и настройки печати | Нет |

**Дополнительная договорённость:** выделенный текст → контекстное меню «Отправить в заметки» → создать файл заметки в **той же папке**, что и исходный документ. Это пока не реализовано.

**Не считать полнотой** отрисовку вкладки без работающих команд. Готовность означает испытание в независимом `Documents.tea`, запущенном внутри установленной StyleOS, после F10 и после повторной загрузки системы.
