# StyleOS — первый проверяемый перенос функционала 730 из восстановленной 709

База этой линии: точный исходный Git-коммит 709 `f81631d980824f2338ae68eaca0a7c549cc8161f`. Перенесены только 15 изменённых файлов из **отдельной новой реализации** F5 (`a0401cebc26e7119bcf7a8aef48ba659f1d25db9`) с исходными Git blob SHA; её историческую workflow не копировали, вместо неё в новой ветке усилили обязательный CI.

## Реализовано в этом переносе
- Отдельный `desktop_sessions` runtime с учётом PID записей приложений.
- Независимые несохранённые UTF-8 черновики редактора и заметок, F3/F5, F8 и F10.
- Перестройка интерфейса без очистки этих черновиков; ограниченное подтверждение F10 по пикселям и UART.
- Проверки сохранения заметок в StyleFS v2 и отказов PID на хосте.
- Обязательные QEMU/OVMF сценарии F8/F10 и F3/F5/F10 включены в CI этой ветки.

Это точный перенос **восстановленного нового кода**, не найденный оригинал C/ASM сборки 730. PID на данном этапе — реестр сеансов, **не аппаратно изолированные процессы**. Копирование двух томов, графический установщик 730, настоящая система .tea и полный Deep Drop ещё не интегрированы. Контрольные оригинальные 730/744 не менялись. Не заявлять PASS в новом CI до появления фактического результата.

См. `730-functionality-baseline.md` и исходный F5 отчёт `730-notes-f5.md`.
