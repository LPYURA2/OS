# План Termux → Proteus: критерии приёмки (12.11.2026)

## T0 — База и контроль воспроизводимости (частично подтверждён)
- [x] Аудит версии v0.2; старые самотесты.
- [x] Отдельная папка экспериментальной v0.3; не перезаписывать диск v0.2.
- [x] Положительные тесты гостевой оболочки и сохранения блока через перезапуск CPU.
- [x] Экспорт бинарников M32 с SHA-256, повторная проверка.
- [ ] Пользовательская проверка на конкретном Android/Termux (скриншот и журнал).

## T1 — Заморозка единой аппаратной платформы
- [ ] Утвердить единую ISA CPU (кандидат RV32I/RV32IM, не принято).
- [ ] Зафиксировать PC, регистры, режимы, карту памяти, MMIO, ABI, таймер, UART, диск.
- [ ] Повторяемый ROM→RAM boot и загрузка kernel.bin без Python-подмены.
- [ ] Интеграционные и негативные тесты, эталонные трассы первого 1000 тактов.

## T2 — Freestanding ядро на C/ASM
- [ ] Кросс-компилятор и linker script для выбранной ISA.
- [ ] Запуск кода ядра с аппаратными прерываниями, системными вызовами.
- [ ] Пользовательские процессы, разделение памяти, обработка ошибок.
- [ ] Схема IPC и распределения RAM.

## T3 — Файловая система
- [x] Эксперимент: одна NOTE.TXT в секторе 80, данные переживают reboot.
- [ ] Настоящий формат тома, имена файлов, каталоги, метаданные, ошибки, свободные блоки.
- [ ] Монтирование и восстановление после неожиданного завершения.
- [ ] Тесты целостности при перезапуске.

## T4 — Системные утилиты
- [ ] Полноценная гостевая оболочка, ls/cat/cp/mv/mkdir и редактор.
- [ ] Гостевой диспетчер задач (PID, CPU, RAM, остановка задач).
- [ ] Запуск исполняемых файлов с виртуального диска.

## T5 — .tea как нативный формат
- [ ] Формат manifest, ABI, пакет и исполняемое содержимое.
- [ ] Установка, запуск, обновление, удаление.
- [ ] Две независимые программы и тест прав доступа.

## T6 — Графика и ввод
- [ ] Framebuffer как часть виртуального железа.
- [ ] Мышь/сенсор/клавиатура, обработка событий гостевыми драйверами.
- [ ] Рабочий стол, окна, курсор, оконный менеджер.

## T7 — Прикладные программы
- [ ] Гостевые проводник, настройки, редактор, калькулятор.
- [ ] Основа движка для гостевой системы: C/C++ ABI; последующие FFI планируются.
- [ ] Тест нескольких приложений одновременно.

## T8 — Критерии перехода к Proteus
- [ ] Зафиксированная ISA и карта устройств, документация для моделирования.
- [ ] Единый boot ROM, kernel.bin, disk image; проверяемые SHA-256.
- [ ] Повторяемые тесты ROM/CPU/MMIO/таймера и набор golden traces.
- [ ] Пройден полный сценарий: boot → shell/GUI → файлы → процессы → reboot → данные.
- [ ] Согласованная приемка владельца и отдельная матрица реального Termux-устройства.

**Proteus:** сначала воспроизвести ROM, ALU и регистры CPU и эталонные трассы, затем память, I/O, прерывания и загрузку гостевого кода. Реалистичность запуска полноценного GUI в медленном логическом симуляторе ещё неизвестна.

**После Proteus:** x86-64-порт для PC/Limbo (другая двоичная сборка), ARM64-порт, затем совместимость APK/EXE. Это не задачи текущей версии.
