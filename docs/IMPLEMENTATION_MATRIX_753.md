# «Документы»: матрица утверждённого альбома

Источник: `StyleOS-Documents-Full-Concept.pdf` (обложка + 14 экранов).
Это требования к восстановлению интерфейса, **не список реализованных вкладок**.

| Макет | Назначение | Состояние в восстановительном источнике 753 |
|---|---|---|
| 01 Старт | Новый, открыть, недавние | Нет UI |
| 02 Файл | Открыть, сохранить, импорт, экспорт, печать, версии | Частичный host-only DOCX export |
| 03 Текст | Стили, шрифты, абзацы, списки, поиск/замена | Есть только базовая модель текста |
| 04 Вставка | Таблицы, изображения, фигуры, диаграммы, формулы, символы, колонтитулы | Нет UI/объектной модели |
| 05 Страница | Формат, поля, ориентация, колонки, разрывы | Есть модель бумага/поля, без UI/компоновщика |
| 06 Ссылки | Оглавление, сноски, подписи, ссылки, библиография | Нет |
| 07 Проверка | Орфография, комментарии, изменения, сравнение | Частичные базовые C-модули, нет UI/DOCX track-change roundtrip |
| 08 Автоматизация | Шаблоны, поля, заготовки, источники, слияние, предпросмотр | Нет |
| 09 Вид | Структура, чтение, масштаб, линейка | Нет |
| 10 Свойства абзаца | Выравнивание, интервалы, отступы | Нет |
| 11 Свойства изображения | Размер, обтекание, положение, альтернативный текст | Нет |
| 12 Открыть | Диалог файлов и каталогов | Нет |
| 13 Сохранить как | Диалог выбора имени/папки | Нет |
| 14 Печать | Предпросмотр и параметры | Нет |

Существующие возможности контрольной 744 **не следует** переносить из этого
статуса: здесь говорится только о **восстановленных исходниках 753**.
