Продолжаем разработку StyleOS, репозиторий LPYURA2/OS.

Последний этап — 806. Проверь `docs/NEXT_CHAT_806.md`, `docs/architecture/ACPI_MADT_IOAPIC_TOPOLOGY_806.md`, `AGENTS.md`, `docs/PROJECT.md`. Принятая база 805: `a04be583e86acde0c9ddcc7f957b11cb33584e92`.

Задача 806: отдельный read-only x86-64 EFI исследует ACPI 2.0 RSDP/XSDT/MADT из UEFI configuration table до ExitBootServices. Валидирует проверки целостности ACPI, Local APIC, IOAPIC MMIO-базы/GSI и ISO. После EBS печатает только копию проверенных данных. Существующий Desktop и main без изменений. Для приёмки нужна настоящая QEMU/OVMF, оригинальный UART и успешный полный GitHub Actions. Результаты, SHA и номера запусков возьми из фактического отчёта — не угадывать.

Важно: топология IOAPIC не означает доказанную доставку прерываний. Следующий этап 807 — настоящий IRQ delivery в отдельной диагностике. Затем DMA/IOMMU, UEFI runtime и интеграционный own CR3 со штатным Desktop, приложениями и файлами.

Фундамент StyleOS ещё не завершён. Отдельно сообщить о завершении только после полноценной аппаратной интеграции. Дальше — Процессы, независимые .tea, вход/пользователи, StyleFS/Проводник по утверждённым макетам. На каждом этапе: отдельная ветка, исходники, ISO, доказательства, CI, отчёт и сообщение для нового чата.
