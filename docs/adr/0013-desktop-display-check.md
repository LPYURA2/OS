# ADR-0013 — первое графическое испытание x86-64

Статус: изолированная диагностическая ступень первого образа StyleOS.
Основа — принятый в Termux коммит `40c3987d4b78e0f67888db8d6baa24c7af4a35d0`.
Это не новое решение о совместимости приложений, драйверах, API или ABI.

## Решение

Добавить отдельный флаг `--test-desktop-display` только для x86-64 UEFI.
Флаг не совмещается с прежними тестовыми профилями. В обычном образе новый
код не линкуется. Тот же `boot_info v1` используется без расширений и без
размещения указателя на firmware-протокол в общих структурах.

До окончательного получения карты памяти UEFI-адаптер читает параметры активного
режима Graphics Output Protocol и копирует только числовое описание поверхности
в образ. После `ExitBootServices` вызовов firmware нет. После успешной диагностики
карты ядро рисует проверочный кадр напрямую в линейный framebuffer. Поддержаны
только ограниченные 32-битные RGB/BGR-режимы с достаточным размером и допустимым
шагом строки. Отбрасываются пересечения диапазона записи с объектами загрузки и
диагностическими RAM-диапазонами. Адрес относится к доверенному виртуальному
устройству этого эксперимента. Это не универсальный механизм допуска MMIO.

Отказ GOP или неподдерживаемый режим не должен приводить к записи в память
или выдаваться за успешную отрисовку. COM1 остаётся рабочим каналом диагностики,
а гостевая система завершает диагностический путь остановкой ядра.

## Границы первого образа

Проверочный экран намеренно помечен **DISPLAY CHECK**. Это не макет, не интерактивная
оболочка и не готовый первый пользовательский образ. Следующая проверка на целевой
VM — загрузка и вывод под VirtualBox. Дальше необходимы ввод, реальный отдельный диск
данных, учёт пользовательских и системных процессов, текстовый редактор, файловый
менеджер и панель процессов. Тестовый экран не подменяет ни один из этих результатов.

Вариант рисовать средствами UEFI до входа в ядро отвергнут для этого опыта:
успешный кадр должен появиться после прекращения работы Boot Services и
после проверенного входа самого ядра. Полноценная модель дисплеев и общий
путь ПК/телефон с внешним монитором не фиксируются этим экспериментом.
