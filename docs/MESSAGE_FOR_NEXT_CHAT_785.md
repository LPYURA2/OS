# Сообщение для нового чата — StyleOS после этапа 785

Продолжаем разработку StyleOS в репозитории `LPYURA2/OS`. Изучи `AGENTS.md`,
`docs/PROJECT.md`, `docs/NEXT_CHAT_785.md`,
`docs/architecture/INACTIVE_IST_GUARD_TABLES_785.md` и утверждённые макеты
`docs/design/APPROVED_UI_REFERENCES.md`.

Сохраняй принятые ветки, `main`, прежнюю историю и существующий отработанный
рабочий стол без изменений. Каждому новому этапу отдельная ветка от точного
последнего принятого SHA. Не путай программные тесты и аппаратные доказательства.

При 784 в QEMU успешно прошли `LGDT/LTR/STR`, но guard-страницы и IST не
проверялись аппаратно. Этап 785 подготовил отдельный *неактивный* набор
таблиц для NX supervisor IST1 и двух guard PTE, с негативными проверками.
Перед продолжением сверь CI и точный SHA 785, не считай его завершённым
без SUCCESS. Следующий шаг — аппаратный 786: реальное исключение через IST,
активные guard-страницы в новом CR3 и независимая строгая проверка QEMU;
никакого возврата в UEFI после установки дескрипторов.

Общий порядок разработки после завершения фундамента: доделать «Процессы»,
сделать нативные `.tea` полностью независимыми от оболочки, реализовать
пользователей и экран входа/выбора пользователя по утверждённым макетам,
затем довести StyleFS и Проводник строго по утверждённым макетам (раздел
«Быстрый доступ», никаких «Рекомендованное»). Дальше установщик, App World,
Интернет, звук и VPN. Не изменять палитру текущего Desktop. Не предлагать
объединять в main без согласования.

На каждом этапе дай ISO из успешного CI, полный архив исходников, доказательства
проверок, ссылку на коммит и Actions, точку продолжения и это сообщение.
