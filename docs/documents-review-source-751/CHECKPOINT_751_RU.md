# Документы StyleOS — контрольная точка 751-source (не образ ОС)

## Цель
Сохранить независимое ядро вкладки «Проверка», подготовленное при отсутствии
исходного дерева билда 749, отдельно от уже работающей пользовательской сборки.

## Проверено
- Доступный публичный GitHub `LPYURA2/OS` не содержит веток `feature/styleos-documents-*`.
- В архиве владельца `StyleOS-744-Documents-Intermediate.zip` есть ISO,
  VDI, инструкции и скриншот. Исходного `Documents.tea` нет.
- Самостоятельные тесты C11: GCC и Clang — PASS (unit и 40 stress-сценариев),
  AddressSanitizer/UndefinedBehaviorSanitizer — PASS.

## Не проверено
- Реальная интеграция в `Documents.tea` — NOT RUN.
- DOCX `w:ins` / `w:del`, колонтитулы, комментарии, верстка — NOT RUN.
- QEMU, ISO, VirtualBox — NOT RUN для этого исходного набора.

## Следующее необходимое действие
Получить полный рабочий исходный каталог, соответствующий этапу 749;
создать новую интеграционную ветку от него; присоединить модуль и интерфейс
вкладки «Проверка» строго по `StyleOS-Documents-Full-Concept.pdf`, стр. 8.
Сделать round-trip редактируемых изменений в DOCX; прогнать регрессии.
Затем «Автоматизация», сверка всех окон, одна общая приёмка приложения.

## Предохранители
Не трогать `main`, Portable-os, рабочий стол и действующие диски данных.
Все родные приложения поставляются как `.tea`. Не выдавать данный модуль за
готовое приложение или выпуск ОС. Проектный порядок работ не меняется.
