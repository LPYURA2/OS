FADT→DSDT с контрольными суммами, ограниченный статический анализ
AML DeviceOp, PNP0A03/PNP0A08/PNP0C02 и буквальных _SEG/_BBN/_CRS,
с сохранением оригинальных DSDT в аппаратных UART/QEMU логах.

Статические подсказки НЕ являются вычислением ACPI namespace.
Ни _CRS, ни _SEG, ни _BBN как исполняемые методы не подтверждены.
Не считать обнаружение литерала доказательством ECAM reservation,
IOMMU ownership или возможностью DMA.

Следующая ветка: ограниченный реальный AML namespace interpreter,
SSDT и безопасная политика OperationRegion; далее IOMMU ownership,
безопасные DMA-домены и настоящие deny/allow/fault/invalidation,
UEFI runtime и собственный production CR3.

После полного аппаратного фундамента — единая интеграционная приёмка
обычного ядра, Desktop, процессов, .tea и StyleFS. Только затем
сообщить владельцу о завершённом фундаменте.

Затем утверждённый порядок: полные «Процессы» → независимые .tea →
