## Независимая перепроверка Codex

По отчёту проверен `c162995c4390686bda54468f68f40164b3c4f3bc`. Подтверждены цепочка `f81bb5c` → `40c3987` → `c162995` и сохранность трёх файлов двух исправлений.

- Linux — 57/57 полных регрессий, в том числе 299 Python-тестов. Disk-app — 16/16.
- Python 3.14.10 с удалённым атрибутом os.link — 33/33 проверок дискового приложения без пропусков.
- Графика — хостовый тест и 2/2 QEMU-сценария, включая кадр 1280×800 и ожидаемый отказ без VGA. Первая попытка не запустила гостя из-за отсутствия `vgabios-stdvga.bin` в пути поиска. После указания каталога ROM прошло без изменения исходников.
- Обычная сборка не включает графический профиль. 48/48 старых бинарных артефактов совпали с заново собранной базой `40c3987`. Новых регрессий в проверенном объёме не обнаружено.
- Python 3.12.14, отдельно 3.14.10, Clang/LLD/LLVM 19.1.7, GCC 14.2.0, QEMU 10.0.13, OVMF 2025.02. Собственные прогоны аудитора в Android/Termux, VirtualBox и на нативном оборудовании — SKIPPED.

Исходные воспроизводимые материалы — [графический отчёт с UART/JSON](desktop-display/README.md), [отчёт Linux по T‑P1.8B](t-p1-8b/REPORT_RU.md) и [отчёт по T‑P1.8A](t-p1-8a/README.md). Старое SKIPPED в них не исправляется задним числом.
