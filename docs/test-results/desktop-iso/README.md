# StyleOS Desktop v0.3 — загрузочный ISO для x86-64 UEFI

База — `8d13627345329c0bed7ceb816fa39b34bd3f4f4c` (Desktop v0.2).
Код загрузчика, дисковый драйвер, формат хранения заметок и отрисовка курсора
не менялись. «Задачи» переименованы в «Процессы» в меню, заголовке и на панели
задач. Внутри пока список окон оболочки, а не список процессов ядра.

## Запуск в VirtualBox

1. Полностью выключите ВМ. Включите EFI, оставьте Secure Boot выключенным.
   Для новой ВМ используйте один CPU, 256 МБ ОЗУ, VMSVGA (3D выключено), PS/2 Mouse.
2. В настройках носителей отключите прежний **системный** VDI, не удаляя его.
   Подключите ISO к виртуальному CD/DVD. Для IDE PIIX3 используйте освободившееся
   «Первичное устройство IDE 0» (порт 0, устройство 0).
3. Если нужны заметки, оставьте `StyleOS-Data.vdi` на вторичном главном IDE
   (порт 1, устройство 0), как раньше. Без него доступен рабочий стол, но
   сохранение недоступно. Для новой ВМ без прежних заметок можно создать диск
   данных по [инструкции v0](../desktop-v0/README.md).
4. Запустите ВМ с виртуального CD/DVD. Для обновления меняйте ISO только при
   выключенной ВМ. Для отката верните предыдущий загрузочный носитель.

Система запускается напрямую, установщика нет. ISO предназначен для
виртуального оптического привода с UEFI x86-64. Legacy BIOS, USB-загрузка,
реальное железо и AArch64 не входят в этот образ. «Выключить» остаётся
неактивным, как в v0.2. Перед остановкой ВМ сохраните заметки.

## Сборка и проверка

Используются прежние Clang/LLD и Python, стандартные `xorriso`, `dosfstools`
и `mtools`. `tools/make_desktop_iso.py` кладёт готовый `BOOTX64.EFI` в FAT16
образ для UEFI El Torito, а также в обычное дерево ISO. `tools/build.py` и
обычные системные образы не изменены.

```sh
python3 tools/build.py --arch x86_64 --desktop-v0 --output build/v0-3-payload
python3 tools/make_desktop_iso.py \
    --efi build/v0-3-payload/x86_64/BOOTX64.EFI \
    --output build/StyleOS-Desktop-v0.3-x64.iso
python3 tools/test_desktop_v0.py \
    --boot build/StyleOS-Desktop-v0.3-x64.iso \
    --previous-boot /path/to/StyleOS-v0.2-System.vdi \
    --data-template /path/to/clean/StyleOS-Data.vdi \
    --output build/desktop-iso-test
python3 tools/test.py --all --output build/desktop-iso-regression
```

Тестовый диск перед загрузкой копируется. Не передавайте раннеру рабочие
заметки, сценарии теста предполагают исходный пустой шаблон v0.

| Проверка | Результат |
|---|---|
| Два ISO независимо упакованы из одной сборки, каталог El Torito содержит UEFI-оптическую запись, обе копии EFI из ISO совпали с исходной | PASS, ISO побайтно совпали |
| Пустой вход и совпадение входа с выходом через hardlink | PASS, выходные файлы не перезаписаны |
| Чистый запуск ISO без жёсткого диска, затем запуск с VDI заметок | PASS в QEMU/OVMF |
| Курсор поверх окна, локальная перерисовка PS/2, иконки, панель «Процессы», перемещение окон | PASS в QEMU/OVMF |
| Запись заметки прежней v0.2, изменение после замены VDI на ISO, повторное чтение с прежнего VDI, проверка байтов и отказ от записи на чужой диск | PASS в QEMU/OVMF |
| Резервный вариант системного VDI из новой сборки | PASS в QEMU/OVMF |
| Обычные образы и набор регрессий | 57/57 PASS, четыре обычных артефакта побайтно совпали с v0.2 |
| VirtualBox и физическое железо | Не проверены на этой сборке |

## Граница файловой системы

FAT16 внутри ISO нужен только для загрузки прошивкой. Для пользовательских
данных сохранён старый формат `STYLEOS-DESK-V01`: фиксированный диск 2 МиБ,
четыре слота заметок, не более 4096 байт на документ. Это не общая файловая
система и не NTFS.

Предлагаемый отдельный этап — своя версионируемая ФС на новом тестовом образе,
без записи в старый VDI. Первый сценарий должен проверять создание папки,
запись, повторное чтение и переименование файла после перезапуска, а также
отказ при чужой сигнатуре. Перенос заметок следует делать копированием с
проверкой содержимого, оставляя исходный носитель нетронутым. В v0.3 этот
формат и миграция не реализованы.
