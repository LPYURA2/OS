# StyleOS v0.7, сборка 705 — управление и папка обновлений

Ветка `feature/styleos-desktop-input-updates` от принятой
`feature/styleos-explorer-v2` (`bce3eaf`, сборка 703).
703 подтверждена владельцем в VirtualBox. 705 — следующий тестовый инкремент.
Ветка `main`, прежние образы и старые тестовые пакеты не заменялись.

## Установить на тестовой ВМ со сборкой 703

1. Полностью выключите ВМ. Системный VDI оставьте на первичном IDE 0.
   Сохраните прежний диск данных. Отсоедините его без удаления, подключите
   `StyleOS-705-Transfer.vdi` на вторичный IDE 0.
2. В сборке 703 не нажимайте старый ярлык «Обновления», он ещё ведёт в
   «Загрузки». Откройте **Проводник → Мой компьютер → Диск 2 →
   Обновления** и найдите `Build-705.supdate`. Откройте пакет, подтвердите
   установку и перезагрузите систему.
3. Убедитесь, что «О системе» показывает 705. Проверьте ярлык
   «Обновления», одинарный и двойной щелчки на `Release.txt` и
   переключение английской/русской раскладки.
4. После проверки выключите ВМ и верните свой прежний VDI данных.
   Если на нём ещё нет каталога «Обновления», он создаётся при первом
   открытии ярлыка. Старые пакеты из «Загрузок» не переносятся автоматически.

## Что изменилось

- «Обновления» в «Быстром доступе» открывает одноимённый каталог
  на диске данных. Это не фильтр и не псевдоним «Загрузок».
- Один щелчок по файлу или папке выделяет, двойной щелчок открывает.
  Сохраняются Enter и «Открыть». Пакет обновления двойным щелчком
  открывает подтверждение, но не начинает запись автоматически.
  Если часы для распознавания интервала недоступны, работают
  одиночное выделение и явное «Открыть».
- RU/EN в правой части нижней панели — кнопка. Alt+Shift переключает
  ту же раскладку один раз за нажатие, порядок клавиш не важен.
  F6 оставлен как резервный способ. Меняется раскладка, не язык интерфейса.
- Формат StyleFS, разрешение записи и формат подписанного пакета
  не менялись. Заметки, собственная работа с DOCX и развитие Deep Drop
  по-прежнему отдельные этапы. [Текущий план](../../ROADMAP.md).

## Подтверждения

- QEMU/OVMF, реальный PS/2 через QMP: 703 → 705, самостоятельный
  каталог, нет записи в уже подготовленный VDI данных, создание
  пустой папки на старом томе без переноса скачанного пакета.
- Один щелчок и два разнесённых по времени щелчка только выделяют,
  двойной открывает текст. Щелчок по RU/EN и Alt+Shift в обоих порядках
  дают ровно по одному переключению.
- VirtualBox для 705 пока не проверялся. Принятая база для основной ВМ — 703.
- Старый сценарий с Диском StyleFS v2, сохранением текста, Deep Drop и
  побайтной копией DOCX прошёл в QEMU. Штатные регрессии x86-64/AArch64
  — 57/57.
