# StyleOS v0.7, сборка 707 — пакет обновления с ПК без смены дисков

Ветка `feature/styleos-live-update-import`, база `e054f28` (705).
Выпуск тестовый. Передача пакета в уже запущенную StyleOS и установка
подписанного пакета — разные действия. Импорт никогда сам не меняет
системный диск и не перезагружает ВМ.

## Первый запуск

Старая сборка не умеет принимать файлы с ПК. Для перехода на 707
используйте последний раз прежний способ: на выключенной **тестовой**
ВМ, не меняя системный VDI, временно подключите `StyleOS-707-Transfer.vdi`
как вторичный IDE 0. В 705 откройте «Обновления», в 703 войдите в
**Проводник → Мой компьютер → Диск 2 → Обновления**. В этой папке лежит
`Build-707.supdate`. Установите пакет, перезагрузитесь, проверьте 707.
Затем выключите ВМ и верните прежний диск данных на место.

На выключенной ВМ один раз настройте VirtualBox:

- **Настройки → COM-порты / Последовательные порты**.
- Включите последовательный порт со стандартным **COM2**
  (I/O `0x2F8`, IRQ `3`). COM1 для диагностики оставьте как был.
- Режим — **Host Pipe / Канал хоста**. Пусть VirtualBox создаёт канал
  (режим сервера, не подключение к уже существующему каналу).
- Путь — `\\.\pipe\styleos-updates`. Для проверки используйте только
  одну запущенную ВМ с таким именем канала.

Это локальный канал Windows ↔ ВМ. Общая папка, сеть, ISO,
дополнительный драйвер Windows и права администратора не требуются.

## После настройки

1. Запустите StyleOS и оставьте оба штатных VDI на месте.
2. Откройте **Проводник → Обновления → С ПК**.
3. В Windows запустите `Send-StyleOS-Update.exe` и выберите файл
   `.supdate`. Для проверки импорта можно выбрать включённый в архив
   `Build-707.supdate`, если его нет на диске данных. Он появится в папке,
   но установщик не примет уже установленную версию.
4. Для настоящего более нового обновления откройте появившийся пакет,
   нажмите «Установить» и перезагрузите **только ВМ** после подготовки.

Пакет проверяется до записи на диск данных, существующий одноимённый файл
не переписывается. Отмена прекращает передачу. Установка по-прежнему
использует подпись, два слота и механизм отката. Получение документов и
приложений по этому каналу не включено.

## Проверки

- Гость и передача в работающую систему через реальный эмулированный
  COM2 проверены с QEMU. В тесте использовался локальный FIFO и клиент
  с тем же форматом передачи, а не оболочка Windows.
- Подменённый пакет и частично отправленный пакет после отмены
  не создают файл. Действительный пакет сохранён побайтно. Повтор
  не переписывает его, исходный документ не меняется. Сам импорт не
  меняет системный VDI. Установка импортированного 708 проходит
  отдельно и запускается только после подтверждения; 708 — внутренний тест.
- `Send-StyleOS-Update.exe` собран как нативный Windows x64 PE
  с системными импортами. Прогон самого EXE на Windows и проверка
  канала VirtualBox у владельца ещё не выполнялись.
- Формат передачи: восьмибайтная сигнатура `STYHOST1`, длина LE32,
  по 12 байт пакета с квитанцией, последняя квитанция только после
  проверки подписи и транзакционной записи в StyleFS.
- Подготовленный образ 705 принял 707 штатным обновлением. Штатные
  x86-64 и AArch64 регрессии — 57/57.
