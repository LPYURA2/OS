# Desktop v0.2 — отдельная иконка «Файлов»

База — `bce6fe184457cbff97cc81c75f4e04e1e6d468bb`, Desktop v0.1.

- На рабочем столе, в меню StyleOS и на панели задач «Файлы» используют отдельную иконку окна с боковой панелью.
- «Проекты» и каталоги внутри окна сохранили золотые значки папок. Иконка «Заметок», возможности приложений и формат диска данных не изменились.
- Отрисовка курсора из v0.1 сохранена. Над неподвижным столом обновляются небольшие области старой и новой позиции курсора, а при смене подсветки — и изменившаяся часть интерфейса.

## Обновление ВМ

Выключите ВМ. Замените только загрузочный VDI на том же слоте IDE (первичное устройство IDE 0). Существующий `StyleOS-Data.vdi` оставьте на вторичном устройстве IDE 0. Для отката верните предыдущий загрузочный VDI.

## Проверки

- Тесты рендера на хосте — 4/4.
- QEMU / x86-64 UEFI — загрузка итогового VDI, отдельный знак во всех трёх местах, золотая папка «Проекты», локальная перерисовка курсора и подсветки, управление окном, запись заметки на второй IDE-диск и чтение после перезапуска — PASS.
- Штатный набор регрессий — 57/57.
- Повторный запуск именно v0.2 на ноутбуке в VirtualBox — не проверен.
