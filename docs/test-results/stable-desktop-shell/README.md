# StyleOS v0.7, сборка 709 — оформление не зависит от диска данных

Ветка `feature/styleos-stable-desktop-shell` от b46de22 (707).
Проблема воспроизведена на неизменном образе 707: без устройства данных
он показывает старые значки и компактную оболочку. На диске StyleFS
те же код и номер сборки показывают привычный Проводник. Раньше условие
`filesystem.mode` одновременно выбирало, как читать данные и как рисовать
рабочий стол. Порядок загрузки, UEFI-слоты и откат не участвовали.

## Что проверить на установленной 707

Ничего не форматировать и не переустанавливать. В «О системе» видно,
доступен ли диск данных для записи. В VirtualBox → «Носители» у
пользовательского VDI StyleFS должен быть слот «Вторичное устройство IDE 0».
Прежний тестовый StyleFS имеет размер 256 МиБ. Маленький диск заметок старого
формата остаётся читаемым, но не предоставляет новые возможности StyleFS.
Если настройки выглядят правильно, одного симптома недостаточно, чтобы
различить неподходящий диск и сбой распознавания контроллера.

## Что изменено в 709

- Иконки, заголовки и геометрия рабочего стола больше не меняются при
  отсутствии, неизвестном формате или проблеме чтения диска данных.
- Если диск недоступен, Проводник сообщает об этом в новом окне. Он не
  рисует вымышленные файлы. «О системе» различает StyleFS, старый диск заметок,
  нераспознанный носитель и отсутствие видимого диска.
- При исправном StyleFS работает обычный Проводник. Старый диск заметок
  можно читать и писать через прежний механизм с новым оформлением
  окна. Открытие и сохранение заметок по совместимому старому формату
  не превращают его в StyleFS. Системные обновления требуют StyleFS.
- Форматы дисков не менялись. COM2 в этой правке не нужен. Это программная
  поправка оболочки, а не попытка исправить неисправный виртуальный контроллер.

## Проверки

QEMU/OVMF показывает разницу иконок на одной и той же 707 с диском и без
него. В 709 пиксели значков и заголовка совпадают с новым оформлением 707
при штатном StyleFS, отсутствии диска, неподдерживаемом носителе и старом
диске заметок. Старый диск заметок сохраняет и повторно открывает текст.
Неподдерживаемый носитель и исправный тестовый StyleFS проверены побайтно
без изменений. Тест: `tools/test_stable_desktop_shell.py`.

Пакет `Build-709.supdate` подготовлен для существующего механизма
обновления. Его не нужно ставить для диагностики 707. VirtualBox для 709
пока не проверялся.
QEMU: 707 → 709 установлен на прежнем системном VDI, тестовый VDI данных
побайтно совпадает. Штатные регрессии x86-64 и AArch64: 57/57.
