# StyleOS v0.7, сборка 703 — Проводник

Ветка `feature/styleos-explorer-v2` от сборки с автономным обновлением
(`9ddcf97`). Основа интерфейса — два макета владельца проекта:
просмотр обычной папки и экран «Мой компьютер».

## Обновить существующую ВМ

1. Распакуйте архив и полностью выключите ВМ. Системный
   `StyleOS-System.vdi` оставьте подключённым на IDE Primary Device 0.
2. Отсоедините текущий VDI данных из слота IDE Secondary Device 0
   (не удаляйте файл VDI). На его место временно подключите
   `StyleOS-703-Transfer.vdi`. Это отдельный StyleFS-диск,
   где пакет уже лежит в «Загрузках». ISO и новую ВМ подключать не нужно.
3. В StyleOS откройте «Проводник» → «Обновления»,
   выберите `Build-703.supdate` и нажмите «Открыть» или Enter.
   В старой сборке 701 для начала установки нужен ещё один Enter.
4. Перезагрузитесь и проверьте в «О системе» номер сборки 703.
   На диске переноса есть два примера текстовых документов, чтобы
   проверить новую раскладку. После проверки можно выключить ВМ
   и снова подключить прежний диск данных в тот же слот.

## Что изменилось

- Вид папки приближен к макету. Навигационные стрелки, быстрый доступ со
  значками, янтарное выделение, типы и размеры файлов, число объектов,
  рабочие режимы списка и плиток. Поиск по имени в текущей папке учитывает
  латиницу и кириллицу без учёта регистра. Щелчок по полю или Ctrl+F
  начинает ввод, Enter завершает ввод, Esc сбрасывает фильтр.
- В «Моём компьютере» видны системный диск и диск данных, если оба
  распознаны. Карточка второго диска открывает его корень.
  Первый диск из Проводника на запись не открывается.
  Раздел внешних устройств не означает наличия USB-драйвера.
- Файл открывается после выделения кнопкой «Открыть» или клавишей Enter.
  Для обновления доступны «Установить» и «Отмена», Enter и Esc делают
  то же. Аналогичные кнопки есть в окнах создания папки,
  переименования и подтверждения удаления.
- Схема размещения дисков и формат StyleFS не менялись. Эта сборка
  не добавляет работу с Word, USB и загрузку обновлённой системы с ISO.

## Проверки

Сборку 701 владелец запустил в VirtualBox и подтвердил успешное обновление с 700.
Сборку 703 проверяли в QEMU/OVMF. VirtualBox для 703 ещё не проверялся.
`tools/test_explorer_update.py` использует настоящие события PS/2 через QMP.
Внутренний пакет 704 нужен только для проверки следующего обновления мышью.
В архив для владельца он не входит.

- 701 → 703 через существующий механизм обновления: PASS.
- Обе карточки дисков, открытие второго диска мышью, список и плитки,
  поиск кириллицей, открытие файла мышью и Enter: PASS.
- Отмена мышью, отказ повторной установки мышью и Enter,
  подтверждение следующего пакета и перезагрузка мышью: PASS.
- Свежий запуск с новой версией, контрольная сумма VDI данных не
  изменилась: PASS.
- Прежний сценарий StyleFS v2, сохранение текста, копирование DOCX
  и Deep Drop: PASS. 57 штатных проверок x86-64 и AArch64: PASS.
