Продолжаем проект StyleOS (`LPYURA2/OS`). Последний этап 791 — смотри
`docs/NEXT_CHAT_791.md` и `docs/architecture/HARDWARE_WX_PROTECTION_FAULTS_791.md`.

Этап 791 имеет отдельную ветку `feature/styleos-hardware-wx-pf-791`.
Перед работой ПРОВЕРЬ в GitHub Actions успешность полного CI для точного
финального коммита, два реальных QEMU теста RX write #PF и NX fetch #PF,
их UART/CR2/PFEC/RIP/CR3/IST2 и source/ISO. Не доверяй только словам чата.

закрытие системных отображений, MMIO, прерываний и стеков под собственным
CR3, затем безопасная интеграция без поломки Desktop.

Утверждённый порядок после фундамента: «Процессы» (PID/CPU/RAM/управление),
полностью независимые приложения .tea, пользователи/вход по
`StyleOS-Welcome-and-Lock-Screens.pdf`, StyleFS с правами и Проводник по
`StyleOS-Explorer-Mockups.pdf` (раздел «Быстрый доступ»), установщик,
App World, сеть, браузер, звук, VPN. Цветовая палитра и рабочий стол неизменны.
Никаких изменений main или принятых веток. Каждый этап в отдельной ветке.
В конце каждого этапа — архив CI исходников, ISO, аппаратные доказательства,
SHA, ссылка Actions, отчёт, точка продолжения и сообщение для нового чата.
