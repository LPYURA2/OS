Продолжаем разработку **StyleOS** (`LPYURA2/OS`).

**Этап 799 — кандидат до подтверждения финального GitHub Actions.**
Ветка: `feature/styleos-downstream-bar-measurement-799`.
Принятая база 798: `1b3bfec10494660fc27615659af5c5d4cdaf8e60`.

ПЕРЕД ПРИНЯТИЕМ проверь фактический коммит, все обязательные шаги GitHub
Actions, настоящий QEMU UART и SHA-256 CI-исходников/ISO. Нельзя объявлять
SUCCESS только по локальным сборкам.

Изменения: отдельный терминальный EFI измеряет выбранные PCIe BAR1 (32-битный)
и BAR4 (64-битный) VirtIO Serial `01:00.0` за мостом `00:1c.0`, сохраняет
PCI COMMAND и BAR, отключает декодирование для измерения, затем восстанавливает,
проверяет полные диапазоны в окнах моста. Не менять PCI в обычном Desktop.
Не выдавать эти два BAR за все MMIO. Production CR3 остаётся запрещённым.

**План:** фундамент → полноценные «Процессы» (PID, CPU, RAM,
«Процессы»/«Производительность»/«Подробности») → независимые `.tea` →
пользователи/вход по утверждённым макетам → StyleFS/Проводник по утверждённым
макетам (`Быстрый доступ`) → установщик, App World, интернет, браузер, звук, VPN.

Следующий этап 800: эффективное кеширование PAT/MTRR, IRQ/APIC,
DMA/IOMMU, UEFI runtime; затем аппаратная интеграция независимой
защищённой карты памяти с **обычным Desktop и файлами/приложениями**.
Фундамент считать незавершённым до такой приёмки. Только после неё
отдельно объявить владельцу «Фундамент StyleOS завершён».

Сохраняй принятые ветки, main, Desktop, палитру, макеты. На выходе
каждого этапа: полный ZIP исходников CI, ISO, доказательства, точный SHA,
ссылка Actions, отчёт, точка продолжения и отдельное сообщение новому чату.
