StyleOS SDK 0.1 Preview — с чего начать

В комплекте уже есть готовый пример «Презентации»
  artifacts\presentations.tea

Не нужно собирать его самостоятельно. В этот пакет входит тестовый код
для одного текстового слайда. Сейчас StyleOS ещё не умеет устанавливать
и запускать этот формат, поэтому файл не откроется как приложение Windows
или VirtualBox. Это готовый пакет для следующей гостевой проверки.

Первое своё приложение

1. Запусти New-Project.cmd или ярлык New project в меню «Пуск».
2. Введи отображаемое имя и идентификатор. Пример ID: example.my-app.
   Новая папка появится в %USERPROFILE%\StyleOSProjects\example.my-app.
3. Открой main.c в любом текстовом редакторе и поменяй строку message.
   Имя, версию и идентификатор проекта можно менять в app.json.
4. Запусти Build-Project.cmd или ярлык Build project. Вставь или введи
   путь к папке с main.c и app.json. Готовый пакет — build\application.tea.

Чтобы пересобрать «Презентации», запусти Build-Presentations.cmd.
Сборка работает в %USERPROFILE%\StyleOSProjects\presentations и не меняет
исходники, установленные вместе с SDK. Готовый пакет лежит в той же папке.

Проверить пакет вручную в командной строке из папки SDK
  StyleOS-SDK.cmd verify artifacts\presentations.tea

На Windows предназначено только для x64. Компилятор и Python лежат
внутри комплекта. PATH не меняется, сеть для сборки не нужна. Подробности
для разработчика — sdk\README.md. Установка в гостевой StyleOS и конструктор
приложений будут отдельными этапами.
