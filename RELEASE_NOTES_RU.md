# MATRYOSHKA Termux v0.3.2 — T1A

Дата: 12.11.2026. Экспериментальная версия, не стабильная/не полноценная ОС.

**Новая функция:** гостевое ядро M32 самостоятельно загружает и проверяет приложения с системного диска (`MAPP` catalog), запускает новый процесс по `TRAP 10`. В терминале доступны `run 0..4`.

**Сохранено:** ROM загрузка ядра, гостевые процессы, CLI и сохранение NOTE.TXT, 8-битная отдельная ветка M8.

**Проверено локально:** selftest PASS, пять unittest PASS, IMAGE CHECK PASS, M8 SELFTEST PASS, ALU 327680 PASS. ZIP после сборки тестируется повторно. Android-устройство владельца ещё не тестировалось в этой версии.

**Безопасность:** только учебный прототип; checksum не является криптографической подписью; не запускать неизвестный машинный код.

**Совместимость:** предыдущая версия v0.3.1 не изменялась; новый проект запускать в `~/matryoshka032`, пользовательский диск переносить только после резервного копирования.

**Следующее:** Android smoke test, исправление регрессий, согласование единой ISA/ABI и последующие Termux этапы. Proteus пока не начинался.
